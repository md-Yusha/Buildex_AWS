# BuildeX IDE Website

Official website for BuildeX IDE - The AI-Powered Cloud Development Environment.

## Live Site
🌐 **https://buildexide.dev**

## Features
- Responsive landing page
- AI-powered code assistant showcase
- Credit-based pricing plans
- Download links for desktop app
- Cloudflare-optimized delivery

## Tech Stack
- Pure HTML/CSS/JavaScript (no build step)
- Cloudflare CDN
- GitHub Pages hosting

## Local Development
Simply open `index.html` in a browser.

## Deployment
Push to GitHub main branch - Cloudflare automatically updates buildexide.dev
