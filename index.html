BuildeX Documentation & Guides

Interactive Reference for AI Coding & Cloud Workspaces

Welcome to BuildeX Coder IDE

BuildeX is an agentic, cloud-native IDE designed for rapid full-stack and cloud engineering with Amazon Bedrock and AWS serverless architecture.

⚡ 500 Free AI Credits: Every authenticated account receives 500 initial Bedrock tokens. Credits are tracked live in DynamoDB.
Key Capabilities:
  • Zero-Latency Editor: Powered by Monaco Editor with syntax highlighting, IntelliSense, and inline code diffs.
  • Integrated Terminal: Full native PTY terminal with tree process management.
  • Cloud S3 Sync: All workspace zips and chat attachments are persisted directly to S3.

AI Assistant Workflows

The AI sidebar connects directly to high-performance models via Amazon Bedrock Mantle:

  • /plan <goal>: Autonomous multi-step milestone planner that scaffolds code, commands, and files in a single prompt.
  • @filename: Type @ to search workspace files and attach their contents directly as context snippets.
  • Images & Screenshots: Drag and drop or paste any screenshot to trigger multimodal visual code generation with Gemma 3.

AWS Cloud Architecture (ap-south-1)

BuildeX operates on production AWS serverless services:

  • Amazon Bedrock Mantle: Streaming inference via Qwen 3 Coder, DeepSeek V3, Gemma 3 Vision, and Mistral Large.
  • Amazon Cognito: Secure Hosted UI authentication with Google SSO and email confirmation.
  • Amazon DynamoDB:
    • BuildexUsers: Profile, credits, streak, and token analytics.
    • BuildexChats: Full conversation backup and cross-device sync.
    • BuildexProgress: Skill acquisition and step milestones.
  • Amazon S3: buildex-projects-storage-052477895001 for workspace snapshots and chat images.
